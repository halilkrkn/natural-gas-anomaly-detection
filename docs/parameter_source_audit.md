## Audit rule

A source being about natural-gas pipelines is not enough to prove that it contains a specific numerical value. For any “literature-supported” parameter, retain author/year/DOI plus the exact page/table/equation and context. If that evidence is missing, label the parameter **not verified**, **derived**, **explicit-assumption**, or **design-choice** until evidence is captured. Do not close OPEN decisions by creating this table.
